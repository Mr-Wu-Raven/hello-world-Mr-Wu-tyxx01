### 函数
strlen(a) 取字符串长度，要求字符串最后要有\0

strcpy(a, b) 复制字符串,将b复制到a

strncpy(a, b, n) 复制指定长度字符串,将b的前n个字符复制至a，注意a最后手动加\0

strcat(a, b) 字符串连接, 将b跟到a后面

strncat(a, b, n) 连接指定长度字符串，将b前n个字符跟到a后面，最后手动加\0

strcmp(a, b) 比较字符串 a==b:返回0, a!=b:返回1或-1（什么时候1，什么时候-1？？？）

strcasecmp(a,b) 忽略大小写比较字符串,a==b:返回0, a!=b:1或-1

strncmp(a, b, n) 比较指定长度字符串,比较a与b的前n个字符

strchr(a,c) 在字符串中查找指定字符c，若找到则返回指定字符第一次出现的位置到字符串结束的子串

strrchr(a,c) 在字符串中反向查找定字符c,若找到则返回指定字符第一次出现的位置到字符串结束的子串

strstr(a, b) 查找字符串b,若找到则返回指定字符串第一次出现的位置到字符串结束的子串

strrstr(a, b) 反向查找字符串b,或找到则返回指定字符串第一次出现的位置到字符串结束的子串
